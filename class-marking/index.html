    About Class map review

    A MapMaker Labs experiment. It reads the map files that MapMaker saves, compares each student's sketches with your answer map, and keeps your marks and comments in this browser on this device. Nothing is uploaded. The maps are drawn with the ArcGIS Maps SDK, which loads basemap tiles from Esri.
