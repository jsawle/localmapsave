# Experience Builder widgets

`local-save/`: **Local Save** custom widget for ArcGIS Experience Builder Developer Edition (v1.0.0).
It saves the current 2D map to an `.amap` file (web map JSON) on the user's device and opens it again.
See `local-save/README.md` for install, settings and test notes.

This is source code, not a built widget. To use it in an app:
copy `local-save` into `client/your-extensions/widgets/` in Developer Edition.
