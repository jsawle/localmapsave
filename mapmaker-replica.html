This prototype has been retired

The MapMaker replica (prototype 3.0.1) is no longer maintained. The white-label MapMaker app replaces it, with the same tools and more: local save, your own spreadsheet data, map styles you can change afterwards, and a version for each country's own settings.

Maps saved from the replica (.mmap files) open in the new app: Open map, then On this device, then Browse this device.

The replica's code stays in the repository history.
