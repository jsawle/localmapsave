Add a spreadsheet saved as CSV with a location in each row, or a GeoJSON file. Up to 1,000 rows. You can also drag a file onto the map.

Location formats that work

Latitude and longitude columns (e.g. lat, lon), or one column with both, such as 51.5074, -0.1278, 51.5074N 0.1278W or 51°30'27"N 0°07'40"W.

      About Open Map Sketch

      A demonstration of what can be built without any Esri technology: no ArcGIS code, services, basemaps or accounts. It covers sketching, adding your own data and saving the map to a file on your device.

      Nothing you draw or import is sent to a server. Map tiles come from the basemap provider you choose, which sees your IP address as any website does. The OpenStreetMap tile servers are run for light use, so a real deployment would need its own tile provider.

      Save writes a standard GeoJSON file (.geojson). Other GIS tools such as QGIS can open it; sketch styles and bookmarks are only understood by this app.
